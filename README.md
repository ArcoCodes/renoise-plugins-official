# renoise-plugins-official

Official Claude Code plugins by Renoise.

## Plugins

| Plugin | Description |
|--------|-------------|
| [video-maker](./plugins/video-maker) | Video production toolkit |

## Installation

1. Add the marketplace:

```
/plugin marketplace add renoise/renoise-plugins-official
```

2. Install a plugin:

```
/plugin install video-maker@renoise-plugins-official
```
